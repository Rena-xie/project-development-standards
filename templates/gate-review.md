| --- | --- | --- | --- |
|  |  | `PASS / FAIL / NOT_RUN / BLOCKED / N/A` |  |

结果使用规则：

- `PASS`：有充分证据证明满足标准。
- `FAIL`：不满足、证据不足或无法验证。
- `NOT_RUN`：本次未执行，不能据此判定通过。
- `BLOCKED`：因环境、权限或依赖无法执行，不能据此判定通过。
- `N/A`：不适用条件成立，并写明可验证原因；未知不能标记为 `N/A`。
